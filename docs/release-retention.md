# 版本保留说明

## 持续执行的发布保留规则（2026-10-05 更新）

1. 正式版发布成功并完成签名／公证、安装验收与公开下载校验后，清理所有版本号更旧的 Beta Release、其全部资产及同名云端标签。同版本 Beta 也早于正式版；按版本号比较，不按上传时间判断。更高版本的 Beta 不属于本次清理范围。
2. 保留全部正式版发布、正式版标签、完整云端 Git 提交历史和现有分支；禁止截断历史、改写提交或强制推送。删除 Beta 标签前，确认对应提交仍能从保留的云端引用访问。
3. 本地交付产物只保留最新安装包。旧安装包、校验文件副本、构建／测试产物、工作应用副本、空挂载目录及本地发布证据均列入清理；校验值与必要验收结论保存在云端 Release 和仓库文档。
4. 开发源码、本地 Git、工具链、凭据与签名配置属于必要发布环境，继续保留。已安装应用、模型、个人设置及作品不属于发布产物清理范围。
5. 每次构建完成后必须整理准确清单、保留项和影响，按用户 AGENTS.md 取得该清单的批准后执行；同一清单已获批准时不重复询问。清理后核对所有目标、受保护文件和云端下载入口，不把未删除的文件报告为已清理。

以上规则用于后续发布，优先于下方历史记录中的旧保留方案。
