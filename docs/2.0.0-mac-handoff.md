# Aurora 2.0.0 · Mac 正式版构建交接

Windows 端从本次源码发布 2.0.0 正式版。请在 Mac 使用 v2.0.0 标签或同一 Release 的 Source.zip，保留本机未提交修改，不覆盖工作区。不能将 Beta 4 的 DMG 重命名为正式版。

## 本轮变化

共享 LocalizationService 补齐自有日志、任务与模型维护提示的四语言。MacRuntime 的启动日志加入 [Aurora] 本地化说明，原始进程输出不变；RuntimePages 的维护日志增加本地化开始/结束记录。日志写入异常不得阻止维护状态恢复。

模型运行参数、签名、公证、回退条件和上游原文保持不变。Windows 的 61 项日志回归不能替代 Mac 实机验收。

## 构建和验收

1. 确认 Mac csproj Version 为 2.0.0，按 macOS-release.md 使用现有 Apple Silicon 签名、公证流程构建。
2. 运行 MacTests、Python 桥接回归和 install-update.swift 的 UPDATE_REPLACEMENT_TESTS。
3. 实机检查四语言日志和维护提示；原始模型输出、退出码、路径不被翻译或丢弃。确认日志位置不可写时不会卡住维护状态。
4. 在隔离应用与数据目录中验证 Beta 4 升级到 2.0.0、重启、数据保留和显式回退到较早正式版；正常更新仍不得隐式降级。
5. 至少完成受影响功能的短样本；签名、公证、Gatekeeper 通过后，上传 Aurora-Audio-Studio-2.0.0-arm64.dmg 及同名 .sha256 到现有 v2.0.0 Release。

不要覆盖 Windows 安装包、源码 ZIP、校验文件或移动标签。若必须修复 Mac 源码，记录真实构建提交与独立源码，不冒称与原标签字节一致。

上传后核对远端大小和 SHA-256，再将官网/README 的 Mac 正式版 1.9.9 标注及下载链接更新为 2.0.0。此前保持 Mac 1.9.9 正式包与 Beta 4 可下载，不删除历史版本。

当前 Windows 任务没有已连接的 Mac 执行主机，因此未自动启动 Mac 构建；本文件与源码构成后续交接。
