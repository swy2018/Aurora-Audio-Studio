# Mac 2.0.1-beta.1 发布验收

2026-09-30，在 Apple M5 Pro（24 GB）、macOS 27.0.1 上验收。安装包来自 `v2.0.1-beta.1` 标签，源码提交 `d2b398e269089b37dd52552645f306f6c801cdf8`，数值构建号 `2000101`。后续主分支文档变更不改变此安装包的源码身份。

## 分发验证

- Apple Silicon / macOS 26+；Developer ID 签名，338 个内嵌组件和主应用按顺序签署。
- 57 个原生组件具有 arm64 架构；动态库未引用本机构建目录或 Homebrew 路径。应用包含 FFmpeg、FFprobe、SoX、uv 与对应依赖。
- Apple 公证 `Accepted`：`fb8572ba-9728-461e-9698-aa97f9a0faa3`。装订票据、Gatekeeper、应用签名及 DMG 校验通过。
- DMG SHA-256：`954568df0162101ac68966ada1580fdd00969b82c88083ea54bc469c64dc3ba1`。
- 使用隔离应用副本实测 2.0.0 → Beta → 显式回退 2.0.0；安装器等待正在运行的父进程退出，替换后自动重新打开。设置、项目与输出哨兵文件的 SHA-256 不变。
- GitHub 资产大小与 SHA-256 回读、重新下载后的逐字节比对通过；官网清单四种平台／通道选择通过。此 Beta 补充至已有预发布，Windows 资产、版本标签及 2.0.0 正式版保持不变。

## 回归与实机界面

- Mac 回归 106 项、Python 单元回归 33 项、工作区 24 项、存储保护 12 项、输出结构 36 项、运行日志与本地化 61 项、Swift 替换及回退 5 项通过。
- 141 个原生文案键无缺失英文；576 组工作台文案资源具备四语言；官网下载通道策略和元数据同步检查通过。
- 四语言原生界面切换、日语模型列表、内嵌工作台、真实配音的自动收录与音频播放、时长／声道摘要、已安装模型筛选实测通过。上游工作台自身仍可能保留原始中英文标签。
- 应用内六轨分离完成，七个 WAV（六轨及额外伴奏混音）进入成品库。“全部分轨转 MIDI”保留已加入的草稿，得到六个唯一音轨，排除额外伴奏混音。
- 模拟任务记录位置被占用：已有记录保留，新任务提交被阻止，显示重新连接入口；恢复位置后按钮重新可用。退出及重新打开后记录与草稿仍在。
- NuGet 含传递依赖的漏洞查询未报告已知漏洞；不代表不存在未知漏洞。

## 边界与测试环境说明

未覆盖 Intel、其他 macOS 版本、全部可选模型、长素材和真实拔盘场景。MIDI 文件合法及含音符，不代表逐音符准确，应人工校对。没有更换本机已安装的 2.0.0。

通用 Windows 行为测试整套在 Mac 上遇到硬编码 `ffmpeg.exe` 路径断言，未记作整套通过；本轮使用上述 Mac 回归及可移植专项测试，并以正式包内的 FFmpeg 完成原生素材预检。首次 Python 全量发现因管理环境缺少推理专用依赖而导入失败，之后分别使用管理环境运行单元测试、现有模型环境运行真实推理。首次升级保护测试的夹具用了错误的自动更新设置字段，导致应用正常保存检查日期；改为真实字段并重新进行完整往返后，文件哈希保持不变。
