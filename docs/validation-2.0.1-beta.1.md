### 真正产生结果的短样本

| 工作流 | 本轮实际运行 | 结果 |
|---|---|---|
| 音乐 | ACE-Step 1.5 XL Turbo | 生成 WAV，校验并自动入库 |
| 配音与声音克隆 | Qwen3-TTS 1.7B CustomVoice；Base | 合成及克隆短文本 WAV，校验并自动入库；Base 产物 5.36 秒、24 kHz、单声道 |
| 歌声转换 | Seed-VC 44.1k | 短参考音频转换 WAV，校验并自动入库 |
| 分轨 | Vocals Revive V3e；BS-RoFormer-SW | 二轨与六轨独立 WAV；额外伴奏混音保留，但批量 MIDI 交接不重复添加 |
| MIDI | TransKun V2；YourMT3+ | 实际生成含音符的 MIDI，校验并自动入库 |
| 字幕 | Whisper Large v3 Turbo | 生成 SRT 与 JSON，校验并自动入库 |

这验证的是短样本端到端可用性，并未对长素材、所有可选模型或音符识别准确率作承诺。可选 ByteDance Piano 在此机器缺少权重，实测被完整性检查正确阻止；没有为验收下载该模型。Piano 的 CPU/CUDA 选择代码已更正，但它的真实推理仍待具备权重的环境验证。

默认声音克隆的首轮补测使用了与参考文字不一致的旧录音，处理明显变慢，测试已主动中止。随后使用本轮 CustomVoice 生成、参考文字已知的录音完成复测，成功生成并入库。失败／中止记录保留，不算入通过结果。音乐、配音、歌声转换、克隆产物另经音量统计检查，均有非零音频信号。

保留按时间戳／长度失效的有界解析缓存，复用目录枚举得到的元信息，并将 Windows 界面刷新读取移到后台。保存、外部编辑、移动记录与排序都有回归。未引入数据库、插件框架或新的推理依赖。初次实验逐文件重复查询属性导致冷读取退化，已弃用；以上是最终复测值。

性能模式检查范围为 `ProjectService.cs`：无参数字符串比较、`Substring`、同步等待异步、`stackalloc`／重复 `ValueTask`／逐次新建 `HttpClient` 六组高风险扫描均为 0 命中；已存在的序列化选项复用被保留。本次保留的优化以以上量测及缓存一致性测试为依据，并非全仓机械重写。

## 必须保留的限制

Mac 原生 UI、推理和签名留待 Mac 验收，详见交接文档。WAV/MIDI/SRT 的结构校验不能保证音乐识别准确；不将 AI MIDI 宣传为可直接演出的总谱。FFmpeg 解码预检检查开头 1 秒而非完整重编码；后续真实处理仍需成功产出并通过结果校验。

实现参考：[FFprobe](https://ffmpeg.org/ffprobe.html)、[WAVEFORMATEXTENSIBLE](https://learn.microsoft.com/windows/win32/api/mmreg/ns-mmreg-waveformatextensible)、[WinUI 媒体控件](https://learn.microsoft.com/windows/apps/develop/ui/controls/custom-transport-controls)。测试与静态审查仍可能遗漏边界问题，应结合后续用户反馈与实机复验。
