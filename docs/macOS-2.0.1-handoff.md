# Mac 2.0.1 正式版构建交接

Windows 先发布 2.0.1；Mac 请以 `v2.0.1` 标签源码原生构建，不复用 Windows 编译输出。现有 Mac 2.0.0 正式包与 2.0.1-beta.2 保留，不能改名充当新正式包。

本轮主要修复 Windows 后台进程标准输入。Mac 原生 `MacRuntime` 启动器未更改；共享音频预检现在使用有效 EOF 输入管道，维护描述和版本数据同步更新。没有更换模型、框架或依赖。Beta 2 的 Mac 已验收功能仍应做回归，见 [Beta 2 原生记录](validation-mac-2.0.1-beta.2.md)。

1. 阅读 [Mac 发布流程](macOS-release.md)，核对标签、系统与 Apple Silicon 架构，保留用户模型、作品、配置和已有安装。
2. 执行 MacTests 与 Python 环境/生命周期回归；重点核对共享媒体预检、取消/重试、成果入库及导出。
3. 用隔离配置检查四语言、窄窗口、六类功能的实际操作入口，并使用已安装模型完成代表性短素材。仅记录真正运行的模型和设备。
4. 原生构建、Developer ID 签名、公证与装订；验证最终 DMG 后重新生成 SHA-256，记录安装后版本和运行结果。
5. 在 `v2.0.1` 补充 Mac DMG 及校验文件，保留 Windows 安装包、源码包和所有现有资产。更新官网真实资产清单、README、About 与 Mac 验收记录，核对稳定/Beta 的平台选择。

Windows 侧的共享测试或短样本记录不能代替以上 Mac 原生验收。
