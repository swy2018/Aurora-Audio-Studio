1.2.0 专业工作流Professional workflow in 1.2.0

从一份素材，
到可追溯的成品。From source media
to traceable output.

1.2.0 增加清晰的首次使用路径，并把批处理、媒体预览、实时任务状态和成品管理连成一条主流程。Version 1.2.0 adds a clear first-run path and keeps batches, media preview, live task state, and result management in one flow.

  1. 拖入或批量选择素材Drop or batch-select media

    音频和视频在提交前即可预览，并保留大小与格式信息。Preview audio and video before submitting, with format and size visible.

  2. 选择清晰的处理预设Choose a clear processing preset

    快速草稿、推荐质量与高质量会匹配对应的本地引擎。Fast, recommended, and quality presets select the appropriate local engine.

  3. 在任务中心掌握过程Follow progress in Task Center

    查看真实进度、当前阶段、持续时间和引擎日志，也可暂停后续队列。See real progress, stage, duration, and engine logs, or pause the pending queue.

  4. 在成品库继续工作Continue from the Results library

    音轨、MIDI 与字幕按项目和时间汇总，直接打开所在位置。Stems, MIDI, and subtitles are grouped by project and time with direct access.
