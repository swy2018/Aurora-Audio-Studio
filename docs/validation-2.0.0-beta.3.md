## 发布门禁

Windows 安装包必须来自本次提交的 Build Windows installer 工作流。工作流包含 Release 构建、回归、自包含发布、Inno Setup 及隔离安装后真实窗口启动检查。
只有对应提交工作流成功、安装包与 SHA-256 对应、源码 ZIP 排除运行数据后，才将 v2.0.0-beta.3 草稿发布为 Pre-release；不设为 Latest。
最终发布与资产信息以 GitHub Release 为准，此文档记录检查要求，不提前声称发布成功。

## Mac

当前 Windows 主机未连接可执行 Mac 构建的远端环境。MacAppUpdater 的版本/下载测试已在 .NET 测试中通过，不替代 Swift 安装助手、签名、公证或 Mac UI 实测。
请按 beta.3-mac-handoff.md 构建和验收后，将 Mac 包与校验文件补到同一个 Beta 3 Release；不得覆盖 Windows 包或源码 ZIP。
应用替换后的旧应用临时副本清理只在 Mac 源码实现；历史备份未删除，模型回退机制不变。
