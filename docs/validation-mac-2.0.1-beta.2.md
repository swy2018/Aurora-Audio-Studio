# Mac 2.0.1-beta.2 发布验收

2026-10-01，Apple M5 Pro（24 GB）、macOS 27.0.1。Mac 安装包使用 `v2.0.1-beta.2` 标签的源码提交 `7f99ed4a00b3e647c3648210b42ca38fc7337588`，构建号 `2000102`；后续文档维护不改变安装包源码身份。

## 分发与更新

- Apple Silicon / macOS 26+。338 个内嵌组件及主应用使用 Developer ID 签名；57 个原生组件含 arm64，未发现 Homebrew 或构建目录动态库依赖。随包提供 FFmpeg、FFprobe、SoX、uv。
- Apple 公证 Accepted：`9fe8dddd-a7c0-4d7a-bfdc-c4b66dfe0015`；装订、Gatekeeper、安装器自身的应用来源验证通过。
- DMG SHA-256：`d5dcae17853f17bcf1be00ad3b61093c558c36a7c191be216d01ff138448e840`。
- 隔离副本实测 Beta 1 → Beta 2 → 显式回退 2.0.0。安装器等待活动父进程退出，再替换并自动重开；设置、项目及输出哨兵文件哈希保持一致。
- 本机已安装的 2.0.0 未替换；现有模型及运行环境未重装。保持已有 Windows 资产、发布标签、历史版本及正式版通道。

## Beta 2 重点验收

- MacTests 117 项、Python 环境／生命周期／产物等 39 项、问题专项 20 项、工作区 24 项通过。141 个原生文案键无缺失英文，576 组工作台文案资源具备四语言。NuGet 含传递依赖查询未报告已知漏洞。
- 使用自制小型本地 wheel 和真实 uv/venv 验证环境安装、解释器导入、失败保留活动环境、进程取消保留选择、验证后激活、随包权重提取及再次修复。旧候选均保留；没有借助大模型重装。
- Qwen 工作台保留输入时保存主题，连接与输入继续保留；无效路径及有效运行目录变更均被拒绝且未结束引擎。生成后从工具页提交任务会提示先结束工作台，原生成仍完成并自动收录。
- Qwen、ACE-Step、F5-TTS、Seed-VC 原生内嵌界面均通过实例身份、Gradio config 和 DOM 就绪检查。音乐启动取消后可再次进入。五份真实引擎 config 另经共享 C# 策略验证；错误实例、空内容、普通“成功”HTML 被拒绝。
- 手选 Demucs 后自动切换为多轨／自定义，应用内实际生成四轨；自定义模式切回二轨后选中对应二轨引擎。共享回归拒绝不匹配的模式。
- 坏项目结构、空草稿、旧项目与原件保留、并发批次保存保留较新索引由 Mac 与工作区专项覆盖。
- 实机检查宽窗口和约 927 点宽的紧凑窗口，日语空白工作台居中、按钮换行、标题完整。验收截图保留在本地 `audit/mac-beta2/`。

## 实际短样本

| 功能 | 模型 | 结果 |
|---|---|---|
| 音乐 | ACE-Step 1.5 | 6 秒 / 48 kHz WAV，MPS + MLX |
| 配音／克隆 | Qwen3-TTS 0.6B CustomVoice、Base | WAV 与最终回执一致，MPS |
| 多语言／多段配音 | F5-TTS | 单段及多段拼接最终 WAV 与收录音频一致，MPS |
| 歌声转换 | Seed-VC | 44.1 kHz WAV，MPS |
| 分轨 | Vocals Revive V3e、BS-RoFormer-SW、Demucs | 二轨、六轨及额外伴奏、四轨，CPU |
| MIDI | TransKun V2、YourMT3+ | 分别包含 16、20 个音符，CPU |
| 字幕 | Whisper Small | 带时间轴的 SRT 与识别记录，CPU |

共 12 项实际产物验证（含 F5 多段）；另通过签名应用的配音界面生成并自动收录、通过应用内 Demucs 生成四轨。测试素材为本地合成语音和钢琴音阶，输出及元数据隔离。

## 边界

这不是所有模型、所有语言、长素材、全部 macOS 版本或 Intel 的完整验收。MIDI 结构合法不代表逐音符准确。环境事务使用真实的小型测试包覆盖边界，不宣称所有上游大模型依赖组合均重装成功。上游工作台仍可能保留其原始语言标签；没有改写上游输出。Windows 专用 UI 与卸载由原发布流水线覆盖，本次没有重新运行 Windows 安装验收。
