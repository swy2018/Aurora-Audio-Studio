# Aurora Audio Studio · Mac 使用说明

适用于 Apple Silicon（M 系列）Mac，系统要求为 macOS 26 或更高版本。Beta 为预发布版本，升级前请备份重要配置。

## 安装

打开 DMG，将 Aurora Audio Studio 拖入“应用程序”。升级前请先退出旧版。
应用内置 .NET 和音频处理工具，无需另行安装 .NET SDK 或 Homebrew。
模型与运行组件需要在模型中心按需下载，请预留足够空间并保持网络连接。

请使用 Aurora 官方发布的安装包，并保留 macOS 的安全检查。开发者签名与 Apple 公证状态以所下载版本的发布说明为准。

## 开始创作

1. 在模型中心选择所需模型，安装后检查模型状态。
2. 进入对应功能，选择模型，添加素材或输入创作描述。
3. 开始处理后，在任务中心查看进度，在成品库预览和导出结果。

Mac 版提供音乐创作、配音与声音克隆、歌声转换、音轨分离、MIDI 扒谱和字幕制作。
各模型的硬件要求、平台支持情况与许可证会在模型中心列明。建议先处理一段短素材，确认设备兼容性与输出效果。

标注为“仅模型管理”的六个模型仅支持下载、检查、更新和回退，不能在 Aurora 内生成内容。
MiniMax-Music3 当前需要 CUDA，Faster-Whisper XXL 没有 Mac 版本；Mac 字幕功能可使用 Whisper Small、Large v3 Turbo 和 Large v3。

Subtitle Edit 可在模型中心安装。在成品库打开字幕预览后，选择“Subtitle Edit”可继续校对。保存的是成品副本，不修改导入的原始素材。

## 成品与任务

- 成品库支持音频预览、MIDI 信息查看、字幕校对与导出。同名导出文件自动编号，不覆盖原文件。
- 工作台保存最终音频，并记录生成时的模型版本与计算设备。
- 中断任务可使用保留的素材和参数重新处理，不会从中断的计算步骤继续。
- 迁移项目时请同时保留素材；另一台电脑上的素材位置需要重新选择。

## 应用更新与回退

在设置中选择应用更新通道并保存。正式版适合日常使用；测试版通道包含 Beta 和后续正式版。切换通道本身不会降级应用。

在“设置”或“关于”中选择“回退到上一个正式版”，可查看早于当前版本、且提供 Mac 安装包的最近正式版。正式版和 Beta 均可使用此功能。确认目标版本后，Aurora 会下载安装包并校验完整性、开发者签名和 Apple 公证，再替换当前应用。

安装成功后不再保留旧应用副本。替换失败时会尝试恢复原应用。此调整不删除历史备份，也不改变模型自身的备份与回退机制。

回退会保留模型、配置和成品，但旧版可能无法读取较新版本的配置或记录，请先备份重要数据。没有合适的正式版或安装包未通过校验时，不会更改当前应用。

## 存储与资源

设置默认保存于 `~/Library/Application Support/Aurora Audio Studio`，模型默认保存于 `~/Aurora/Models`，输出默认保存于 `~/Aurora/Output`。升级应用不会删除这些目录，已设置的保存位置会保留。

卸载模型不会删除创作成品。更新、回退或卸载使用中的模型前，请先结束相关任务和工作台。
大型模型需要较多内存；24 GB 内存设备建议一次运行一个大型任务。

## 使用限制

- 当前提供 Apple Silicon 安装包，不支持 Intel Mac。
- 当前实机验证环境为 macOS 27 beta，其他受支持系统版本仍需进一步验证。
- 部分内嵌工作台首次加载时可能短暂调整大小。
- 生成结果会受模型、硬件、精度和随机设置影响，不同设备的输出可能不同。
- 请遵守模型许可证、音频版权与声音使用授权，不得冒充他人。
