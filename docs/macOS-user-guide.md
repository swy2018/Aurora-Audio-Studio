# Aurora Audio Studio · Mac 使用说明

版本：1.9.9，Apple Silicon（M 系列），macOS 26 或更高版本。

## 安装和打开

打开 DMG，将 Aurora Audio Studio 拖入 Applications。升级前先退出旧版。
应用内置 .NET 和音频处理工具，不需要另装 .NET SDK 或 Homebrew。
模型和 Python 运行环境不在安装包内，首次使用在「模型中心」安装；需要网络和额外磁盘空间。

开发者签名与 Apple 公证是两个独立步骤。尚未完成公证的包仅用于本机验收，不应作为已通过 Gatekeeper 的正式分发包。不要关闭系统安全检查。

## 开始创作

1. 在「模型中心」选择所需模型，安装后执行健康检查。
2. 在对应工作台选择模型、输入文字或音频，按界面提示启动。
3. 在任务和成果页面查看进度、播放结果、打开输出文件夹。

Mac 版提供音乐生成、配音与声音克隆、变声、人声/伴奏分离、字幕转写、音频转 MIDI 六类本地工作流。
各模型的接入方式、平台限制和许可见 README 与应用内模型中心。
18 个推理模型已通过真实短任务验收。另有六个模型与 Windows 1.9.0 一样仅提供下载、校验、更新与回退管理，不提供推理工作台。
MiniMax-Music3 当前上游推理依赖 CUDA；Faster-Whisper XXL 上游未提供 Mac 二进制。字幕功能仍可使用 Small、Large v3 Turbo 和 Large v3 模型。
Subtitle Edit 可在模型中心安装。在成品库打开字幕预览，点击「Subtitle Edit」即可在外部编辑器校对；保存的是成品副本，不修改原始导入素材。

## 本版改进

- 首页、最近记录、任务重试和导出行为向 Windows 1.9.0 对齐；导出同名文件自动编号，不覆盖原文件。
- 工作台只收录最终音频，保留生成时的模型版本和设备记录；重新打开应用可补收录并去重。
- 「设置」和「关于」可检查程序更新；下载后校验 SHA-256、开发者签名与 Apple 公证，准备成功才退出旧版，旧应用保留备份。
- 官方发布页暂未提供 Mac 更新包时会明确提示；本地正式安装包仍可用于手动升级。
- 设置中新增“应用更新通道”，保存后生效。默认正式版；选择测试版后可接收 Beta 和后续正式版。切回正式版不会自动降级，将等待更新的正式版。1.9.9 是正式通道，2.0.0-beta.1 是测试通道。

## 现有数据和空间

设置默认保存在 `~/Library/Application Support/Aurora Audio Studio`，模型默认保存在 `~/Aurora/Models`，输出默认保存在 `~/Aurora/Output`。
升级应用不会删除这些目录。已经把输出链接到桌面「AI成果/ai音乐」的电脑会继续使用该位置。
卸载模型不会删除创作成果；正在被工作台使用的模型须先停止相关任务再更新或回滚。
不要在生成过程中同时运行多个大模型；24 GB 内存机型宜一次使用一个重型任务。

## 已知限制

- 本版本仅提供 Apple Silicon 包，没有 Intel Mac 包。
- 当前本机验收环境为 macOS 27 beta；其他系统版本需另行实机验收。
- 某些内嵌工作台首次显示时会短暂调整窗口大小，这是当前 WebView 首帧兼容处理。
- 不保证不同硬件、随机种子或推理精度得到逐字节相同的生成结果；输出格式及工作流按 Windows 1.9.0 对齐。
- 请遵守模型许可证、音频版权和声音使用授权，勿冒充他人。
